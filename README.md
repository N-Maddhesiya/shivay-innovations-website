# Shivay Innovations Website

Responsive multi-page React + Vite website for Shivay Innovations.

## Run locally

1. Extract the ZIP.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Pages
- Home
- About Us
- Services
- Solutions / illustrative concepts
- Pricing
- Contact

## Visual refresh
The refreshed version uses a lighter warm-charcoal palette with stronger orange accents, image-led service cards, service-specific photography, hover zoom/raise effects, and responsive layouts.

## Before publishing
- Replace the contact placeholders in `src/data/company.js` with verified company details.
- Configure a real enquiry submission endpoint; the contact form must not be represented as connected until configured.
- Confirm indicative pricing and service availability with the company.
- Portfolio website and app examples are illustrative concepts, not completed client work.

Service images are loaded from Unsplash image URLs and therefore require an internet connection in the browser.
